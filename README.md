## Pubblicazione
Carica il contenuto di questo ZIP nella radice del repository. In Settings → Pages, seleziona Deploy from a branch, branch `main`, folder `/ (root)`.

Questo pacchetto NON implementa ancora la nuova rete progressiva concordata. Conserva la base esistente per svilupparla senza perdere le versioni precedenti.
